# MzPCG equivalence scenarios: read by both render_cpp.cpp (the original C++ engine, built
# from the MzPCG repository's Source/PCG and MzPCF's Source/PCF) and render_pas.dpr (the
# Pascal port). Each scenario writes <name>.f32 (raw little-endian floats); the two must be
# identical, bit for bit (render_pas --compare). Generated, but edit it as you like.
#
#   scenario NAME RATE [mono]  a new engine, prepare(RATE); settings = the defaults; input a
#                              110 Hz saw (the right channel 165 Hz, from half way); no
#                              timeline. mono: the right channel is null, as for a mono bus
#   set ID VALUE               a pending parameter, as the host holds it (parameter IDs as
#                              in Params.cpp; pattern 1..32, mode 0 GATE / 1 DUCK, rate
#                              0 1/8 / 1 1/16 / 2 1/32)
#   apply                      engine.setSettings(the pending settings, read as the C++
#                              params::Reader reads them)
#   input KIND [ARG]           saw HZ | noise | impulse PERIOD | dc VALUE | silence | tiny
#                              (denormals, alternating in sign)
#   gain G                     scale the input
#   transport PLAYING PPQ BPM  the host's timeline at the top of the next block; while
#                              playing, each block moves it on by its length
#   tempo BPM / seek PPQ       change the tempo / jump (a loop), keeping the rest
#   notimeline                 no timeline: as stopped, position 0, 120 BPM
#   render SAMPLES BLOCK       render in blocks of BLOCK: setHostClock(timeline) then
#                              process, every block, as processBlock does
#   sweep ID FROM TO SAMPLES BLOCK
#                              render, setting ID (and applying) at the top of each block,
#                              from FROM to TO in even steps - a knob turned while playing
#   prepare RATE / reset       prepare again (the host changing its rate) / reset()
#   ftz 0|1                    flush denormals to zero (1, the default: the plug-in runs
#                              under juce::ScopedNoDenormals) or not
#   levels                     every pattern's level on every step, out-of-range ones too,
#                              then stepsPerQuarter of RATE -2..4
#   curve                      the panel's picture of the gain (GainDisplay::simulate) for
#                              the pending settings: its length, then its values
#   end
#
# Every block appends the left channel, the right one (stereo), then step() and gain().

# Mz950 audio equivalence scenarios: read by both render_cpp.cpp (the original C++ engine,
# disk reader and synth) and render_pas.dpr (the Pascal port). Each renders to <name>.f32
# (raw little-endian floats, interleaved left/right unless rendered mono).
#
#   scenario NAME RATE           a new engine at RATE
#   disk FILE                    load an image from the disks folder (the library's .hfe, and
#                                rich.img: the disk check's constructed disk, with S900-blank
#                                filter envelopes, alternating loops and overlapping keygroups)
#   synth N                      render synth preset N to a disk and load it (keeps the
#                                current disk's settings, as the plug-in's re-render does)
#   synthtext TEXT               the same for a recipe given as text (fromText)
#   program N                    the Nth programme on the disk -> buildPatch -> trySetPatch
#   edit KG PARAM VALUE          setKeygroupParam on the current programme (PARAM is the
#                                KeygroupParam ordinal), then rebuild the patch reusing the
#                                last one's sounds and send it - so held notes adopt it
#   crossfade 0|1                force the programme's positional crossfade (header byte 21)
#   nopatch                      send no patch at all
#   trim NAME VALUE              an AtomicTrims value (or gain), stored as a float
#   bendrange / glidetime / widecents / widespread V,  wideoffset 0|1
#   on N VEL [AT]  off N [AT]  wheel V [AT]  pressure V [AT]  bend V [AT]
#   glide 0|1 [AT]  voices N [AT]  wide 0|1 [AT]  alloff [AT]
#   transport BPM PPQ PLAYING QPB   setTransport before every block, ppq advancing while playing
#   render SAMPLES [BLOCK] [mono]
#   end
#
# Only whole numbers and dyadic fractions (0.5, 0.125, ...) appear, so strtod and Pascal's
# Val read every value the same.
#
# KeygroupParam ordinals: 0 HighKey 1 LowKey 2 VelocitySwitch 3 VcaAttack 4 VcaDecay
# 5 VcaSustain 6 VcaRelease 7 VelToFilter 8 KeyToFilter 9 VelToAttack 10 VelToRelease
# 11 VelToLoudness 12 WarpVelocity 13 WarpDepth 14 WarpTime 15 LfoDelay 16 LfoRate 17 LfoDepth
# 18 LfoAftertouch 19 LfoModwheel 20 OutputPort 21 VcfAmount 22 VcfAttack 23 VcfDecay
# 24 VcfSustain 25 VcfRelease 26 Zone1Fine 27 Zone1Transpose 28 Zone1Filter 29 Zone1Loudness
# 30 Zone2Fine 31 Zone2Transpose 32 Zone2Filter 33 Zone2Loudness 34 ConstantPitch 35 LfoDesync
# 36 OneShot 37 VelocityReleaseOn

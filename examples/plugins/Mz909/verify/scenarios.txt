# Mz909 equivalence scenarios: read by both render_cpp.cpp (the original C++ engine) and
# render_pas.dpr (the Pascal port). Each renders to <name>.f32 (raw little-endian floats).
#
#   scenario NAME RATE        new engine, prepare(RATE), pending settings = defaults
#   set ID VALUE              change a pending setting (parameter IDs as in Params.cpp)
#   patch NAME                pending settings = defaults + factory preset NAME
#   apply                     engine.setSettings(pending)
#   on N [VEL]                note on (velocity 100 if none given; 101 or more is an accent)
#   hit VOICE [ACCENT]        engine.trigger(VOICE, ACCENT != 0), VOICE 0..10 (BD .. RC)
#   allsoundoff
#   prepare RATE              prepare again (the host changing its rate), settings kept
#   render SAMPLES [BLOCK]    render, in blocks of BLOCK (default: one block)
#   roms                      append the four ROMs (clock, length, bytes) as floats
#   end
#
# The engine puts rung-out circuits to sleep every 32 samples counted from the top of each
# render call, so the block size changes the output: the odd block sizes check that too.

# The ROMs themselves: synthesized from noise and sines, shaped, 6-bit.
scenario roms 48000
roms
end

# Mz101 equivalence scenarios: read by both render_cpp.cpp (the original C++ engine) and
# render_pas.dpr (the Pascal port). Each renders to <name>.f32 (raw little-endian floats).
#
#   scenario NAME RATE        new engine, prepare(RATE), pending settings = defaults
#   set ID VALUE              change a pending setting (parameter IDs as in Params.cpp)
#   patch NAME                pending settings = defaults + factory preset NAME
#   apply                     engine.setSettings(pending)
#   on N / off N              note on / off
#   bend V / mod V            pitch bend -1..1 / mod lever 0..1
#   keytranspose / legato / allnotesoff
#   host AVAIL PLAYING PPQ BPM
#   ppq V                     the running host position used by hostrun
#   render SAMPLES [BLOCK]    render, in blocks of BLOCK (default: one block)
#   hostrun SAMPLES BLOCK PLAYING BPM   per block: host 1 PLAYING ppq BPM, render, advance ppq
#   end
